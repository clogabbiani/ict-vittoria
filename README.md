# ICT · Liceo Vittoria

Student website for ICT, Year 1. Unit 1: *Can machines think? Hardware and software of a computer system*, aligned with the deck `Inside_the_Machine_IGCSE_ICT.pptx` (4 lessons + review).

- `site_src/content_unit1.py` — all the content of Unit 1 (notes, stories, questions, glossary, practice test). Edit this.
- `site_src/build_site.py` — generates `docs/` from the content. Run `python3 site_src/build_site.py` after every edit.
- `docs/` — the published site (GitHub Pages). Do not edit by hand: `docs/static`, `docs/img` and `docs/about` are kept, everything else is regenerated.

No accounts, no tracking: answers and progress stay in the reader's browser. Image credits: `docs/about/index.html`.
