Review and the test

Everything you need before the test: what it covers, the key terms, one quiz per lesson, the glossary, the timeline and a practice test with model answers.

01What the test covers

  • One written test at the end of the unit, about 50 minutes, in English, no notes.
  • Part A, short questions (about 12 marks): key terms, dates, true/false, match, put in order. Everything in the 'Key terms' table and the timeline can be asked.
  • Part B, exam-style questions (about 15 marks): 'describe' and 'explain' questions worth 2–4 marks each; one mark per correct point. The practice test below shows the style and the model answers.
  • Part C, one longer answer (about 5 marks): the question of the unit, 'Can machines think?', answered with an argument (Turing test or Chinese Room), not only an opinion.
  • The Word deliverable 'Anatomy of a device' (20 marks) is marked separately with the rubric from the lesson.
  • Everything you need is in the four chapters of this site. The Extra page is not in the test.

Lesson 1 · Can machines think?

  • Say what Turing's imitation game (the Turing test) is and why he invented it instead of defining 'think'.
  • Tell the difference between the Bombe (electromechanical, one job) and Colossus (electronic, programmable).
  • Explain Turing's 1936 idea of a universal machine: one machine that runs any program.
  • Define a computer system with the four stages: input, process, output, storage, and tell data from information.
  • Tell hardware from software, and put firmware and data in the right place.
  • Put the key dates in order: 1936, 1941, 1943, 1945, 1947, 1958, 1971, 1981, 2007, 2022.
  • Give three facts about ENIAC (1946) and say who programmed it.

Lesson 2 · Inside the box

  • Draw and explain the von Neumann architecture: CPU (control unit + ALU + registers), memory, input, output, buses, and the stored-program idea.
  • Name what plugs into the motherboard: CPU socket, RAM slots, chipset, expansion slots (PCIe), storage connectors (M.2, SATA), ports, power.
  • Describe the fetch–decode–execute cycle and explain cores, clock speed (GHz) and cache.
  • Explain why GHz alone does not tell you which CPU is faster (cores, IPC, cache, benchmarks).
  • State Moore's law and read the transistor chart (2,300 in 1971 → 28 billion in 2024).
  • Compare RAM and ROM (volatile / non-volatile, read-write / read-only, what they hold) and know what capacity, DDR generation and dual channel mean.
  • Compare magnetic, optical and solid-state storage and know the units bit → byte → KB → MB → GB → TB.
  • Explain why an SSD feels so much faster than an HDD (random access, IOPS) and what NVMe is.
  • Say what a GPU is, why it has thousands of cores, and why the same chips train AI; know VRAM and integrated vs dedicated graphics.
  • Find the bottleneck of a computer for a given task.

Lesson 3 · Input, output and software

  • Name input devices (manual and direct data entry, including sensors) and output devices (for people and for the physical world: actuators), and devices that are both.
  • Classify software: system software (operating system, utilities, drivers, compilers/interpreters) vs application software (general purpose, specialist, bespoke, apps).
  • List the jobs of an operating system and the four kinds of interface (CLI, GUI, touch, voice).
  • Describe what happens when you press the power button (POST, BIOS/UEFI, boot order, bootloader, kernel, login).
  • Explain processes and multitasking, virtual memory, file systems and permissions.
  • Compare Windows, macOS, Linux, Android and iOS and define kernel, shell, distribution.
  • Explain what a driver, a utility, a compiler and an interpreter are.
  • Tell proprietary, open-source and 'free' software apart.

Lesson 4 · From smartwatch to supercomputer

  • Name the types of computer (desktop, laptop, tablet, smartphone, wearable, console, server, mainframe, supercomputer, embedded) with one strength and one use each.
  • Say what a supercomputer and a data centre are, name Leonardo (CINECA, Bologna) and give one environmental cost of the cloud.
  • Describe four emerging technologies: AI / large language models, quantum computing, extended reality, robotics and autonomous vehicles.
  • Explain what the 2024–25 Turing-test studies found and state the Chinese Room argument.
  • Give an argument for and an argument against 'machines can think', using the Turing test or the Chinese Room.
