Unit 1 · Lesson 8

Software, the OS and files

You switch on your phone, open a chat and take a photo. Dozens of programs start, share one CPU and save your files, and you never see them. Who decides what runs?

01The story

7:00. You press the power button. Before you see anything, one program starts first: the operating system (OS). It checks the hardware, copies itself into the RAM and draws the lock screen. Every other app waits for it.

7:05. You open a chat, your music and the camera. There is only one CPU, with a few cores. The OS shares them out, many times a second, so every app seems to run at the same time. It gives each app its own space on the workbench (RAM), and it talks to the speaker, the camera and the Wi-Fi for them.

7:10. You take a photo. The camera app does not know where the bits go on the storage chips. It asks the OS: "save this". The OS gives the photo a name, puts it in a folder and remembers its address. Tomorrow you find it in the gallery. Inside your computer today: the OS is the first program to start and the last one to stop.

02The science

The operating system runs the machine

The operating system (OS) is the program that runs the machine for all the other programs. Windows, macOS, Android and iOS are operating systems. It has six jobs: it starts the machine; it shares the CPU between programs; it hands out space in memory (RAM); it talks to the hardware; it keeps your files in order; and it gives you the screen, with windows and a pointer. Apps ask the OS, and the OS asks the hardware. In the kitchen, the OS is the head cook who opens up in the morning and gives everyone a place on the workbench.

  • The cook = CPU core
  • The metronome = clock (GHz)
  • The countertop = cache
  • The workbench = RAM
  • The pantry = storage (SSD / HDD)

System software or application?

System software works for the other software: the operating system and the drivers. A driver is a small program that tells the OS how to use one piece of hardware, like the Wi-Fi card or a printer. Applications (apps) work for you: a browser, Word, a game. An update is a new version of a program. Most updates are repairs: they fix bugs (errors) and close security holes, so install them soon.

A file: a name, the bits, an address

A file is a set of bits with a name, kept in storage (the pantry). The extension is the end of the name, like .docx, .jpg or .mp3. It is a label: it tells the OS which app opens the file. It is not the truth: if you rename photo.jpg to photo.docx, the bits are still a photo. A folder is a list of files and other folders. The path is the full address of a file, from the drive through each folder to the name, for example C:\Users\Student\Documents\ICT\Rossi_Anna_Unit1.docx.

  • The cook = CPU core
  • The metronome = clock (GHz)
  • The countertop = cache
  • The workbench = RAM
  • The pantry = storage (SSD / HDD)

Name it well, keep three copies

The naming rule: Surname_Name_Task.docx, for example Rossi_Anna_Essay.docx. Who, what, no spaces, no "final". Names like final.docx, final_v2_REAL.docx or Document1.docx tell nobody what is inside. The backup rule 3-2-1: three copies, on two kinds of storage, with one somewhere else. For example: your phone, your laptop at home, and the cloud. The Recycle Bin is not a backup: it is on the same disk, and it gets emptied. A synced folder is not a backup either: sync copies your mistakes, so if you delete a photo on one device, it disappears everywhere.
